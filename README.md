# 학부모 확인서

학교에서 필요한 학부모 확인서를 쉽게 작성하고 서명하여 저장할 수 있는 웹 애플리케이션입니다.

## 주요 기능

- 학생 정보 입력 (학년, 반, 번호, 이름)
- 기간 설정 (시작일, 종료일)
- 유형 선택 (결석, 지각, 조퇴, 결과)
- 사유 입력
- 학생 및 보호자 서명 기능
- 완성된 확인서 미리보기
- PNG 이미지로 저장

## 사용 방법

1. 학생 정보를 입력합니다.
2. 기간을 설정합니다.
3. 유형을 선택합니다.
4. 사유를 입력합니다.
5. 학생과 보호자 서명을 작성합니다.
6. 미리보기 버튼을 눌러 확인합니다.
7. 저장 버튼을 눌러 이미지 파일로 다운로드합니다.

## 기술 스택

- HTML5
- CSS3
- JavaScript
- Canvas API (서명 및 이미지 생성)
- Service Worker (오프라인 지원)

## 오프라인 지원

Service Worker를 통해 오프라인 환경에서도 사용 가능합니다.
